STARFALL ARCHIVE — PRACTICE WEBSITE

WHAT'S INCLUDED
- index.html: the complete practice website (HTML, CSS, and JavaScript in one file)

FEATURES
- Responsive layout designed for phone and desktop
- Working Home / Characters / Lore / Records navigation
- Searchable character catalogue
- Role filters
- Clickable character cards with profile pop-ups
- Fictional lore page
- Sample stats dashboard
- Expandable sealed-note section

HOW TO TRY IT
1. Extract the ZIP file.
2. Open index.html in a browser that can open local HTML files.
3. Tap the navigation buttons and test the character filters/cards.

IMPORTANT
This is a front-end practice demo. The expandable "sealed note" is not secure; it only demonstrates an interface. The website is not published online yet. To share it with story readers, it will need to be hosted (for example, using GitHub and Cloudflare Pages).
